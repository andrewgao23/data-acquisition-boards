# data-acquisition-boards
The **data acquisition** (or sensor) boards on the vehicle is responsible for powering and protecting sensors, filtering sensor telemetry data, and converting it to CAN to be logged.
<br><br>
Until recently, the vehicle ran a 4-board architecture (now dual boards).
